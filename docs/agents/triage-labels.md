# Triage labels

| Skill role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Requires maintainer evaluation |
| `needs-info` | `needs-info` | Awaits information from the reporter |
| `ready-for-agent` | `ready-for-agent` | Ready for agent implementation |
| `ready-for-human` | `ready-for-human` | Requires human implementation |
| `wontfix` | `wontfix` | Closed without planned work |

Use the GitHub label when a skill refers to the corresponding role.
