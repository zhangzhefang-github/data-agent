# 订单问数先确认澄清选项再执行

2026-11-23 确认以下规则。在订单主题空间，一问同时包含未授权的客户姓名和已授权的订单金额时，先说明姓名不可查，等用户确认只查订单金额后再执行。这样用户可以决定只查询获准部分是否满足原问题。

同一会话中，用户可以用「按金额」这样的简短回复选择澄清选项。接续时保留原问题已经给出的条件，并按本轮的空间授权快照核对补全后的请求。见 [ADR 0006](0006-space-authorization-bounds-retrieval.md)。

待澄清问题随会话保留，刷新或重新打开会话后仍可接续。用户明确发起另一道问题时，结束原来的待澄清问题。

聊天流、会话历史和评测读取服务端的同一个问数终态。需要澄清或拒绝时，该轮在执行前结束。
