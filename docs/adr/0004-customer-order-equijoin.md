# 订单主题空间向模型开放客户–订单等值内连接

订单主题空间的授权清单已经点名客户集市，以及已探查、多对一、不会放大行数的客户–订单数据集关系。受限暴露曾把客户集市整表挡在问数上下文之外，客户标识只留在连接键上。2026-11-21 决定：空间点名的数据集进入 Direct SQL 上下文，受限暴露只去掉敏感列。客户标识是订单上的可分组维度。客户表只带这条关系的连接键。姓名、支付关系、raw 和 staging 不进入上下文。模型自行决定是否使用这条等值内连接，执行器按同一份空间授权核对。

这是 [ADR 0003](0003-direct-sql-duckdb-first.md) 所要求的逐条开放。带 Fanout 的支付关系仍然不开放。

2026-11-22，[ADR 0007](0007-readonly-sql-with-fanout.md) 允许空间内的支付表与订单表出现在同一条只读查询里。客户–订单这条等值内连接不变。支付侧要先汇总到订单粒度，订单笔数和订单金额才可以通过。
