空间清单 `spaces.yaml` 的订单空间已经列入 `order_mart`、`customer_mart` 和关系 `order_mart_customer_mart`。语义模型里这条关系是 `orders.customer_id = customers.customer_id`，多对一，`fanout_risk` 为假，验证状态 `profiled`。`customer_mart.exposure_policy` 为 `restricted`。`build_semantic_context` 只把 `exposure_policy == approved` 的数据集放进 SQL 投影，并且数据集集合只取已选指标和维度的来源数据集与空间清单的交集。因此 `customer_mart` 被丢掉，业务对象只剩 order。关系列表按空间清单另选，所以关系还在，两端数据集并不都在。
